# Formes anciennes — crédits

Source : projet *Ancient Chinese Characters* de Wikimedia Commons (https://commons.wikimedia.org/wiki/Commons:Ancient_Chinese_characters_project).
Les 780 images retenues sont toutes dans le domaine public ou sous CC0 (licence relevée fichier par fichier le 16 novembre 2026). Aucune image de Richard Sears (GPL) n’a été retenue.
Quand une forme n’existe pas dans le projet, l’appli affiche « pas de forme connue » : rien n’est dessiné à la place.
Deux caractères simplifiés qui fusionnent plusieurs anciens caractères sont laissés sans forme ancienne : 里 (« dans » vient de 裏, sans forme dans le projet) et 干 (« sec ; faire » vient de 乾 et 幹, pas du 干 « bouclier »).
